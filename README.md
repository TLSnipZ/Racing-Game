# KAGEHAMA — Underground Car Empire

Pre-alpha browser game foundation.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

### Phase 0 scope
- React + TypeScript + Vite foundation
- responsive midnight-Japan visual system
- first starter-car selection prototype
- data-driven starter catalog
- initial navigation shell

Persistent saves, economy, garage simulation and gameplay systems follow in the planned phases.
